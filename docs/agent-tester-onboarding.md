# QuanQuant 測試者連線指南（模擬盤 sim 下單）

給受邀測試「模擬下單」的朋友。全程約 5 分鐘，跟著做即可，不需要任何程式背景。

> **先講三個安心的重點**
> 1. 你下的都是**模擬單（sim）**，不會動到真錢。
> 2. 你的永豐 API 金鑰**只存在你自己這台電腦**，不會上傳到 QuanQuant 網站。
> 3. 需要幫忙隨時找管理員，別自己硬猜。

---

## 一、開始前先準備好

- [ ] **一組永豐「模擬盤（simulation）」帳號**，以及它的 **API Key** 與 **Secret Key**。
      這要自己到永豐申請（本系統不代辦）：<https://www.sinotrade.com.tw/newweb/Api/>
- [ ] **管理員給你的 QuanQuant 登入帳號、密碼，以及網址**。
- [ ] 你自己的 **Mac（Apple Silicon / M 系列）**。（Intel 版 Mac 無法執行，請先告知管理員）

> 沒有永豐模擬帳號 / API 金鑰就無法下單——這步一定要先辦好。

---

## 二、連線步驟

### 步驟 0：先在瀏覽器登入 QuanQuant 網站
用管理員給的網址與帳密登入。**保持這個分頁開著**，等一下核准要用到。

### 步驟 1：啟動 Agent
1. 把管理員給你的 **`QuanQuant Agent.app`**（在 zip 裡）解壓後，放到「應用程式」或桌面。
2. **第一次務必「按住 Control 點一下（右鍵）→ 選『打開』」**，不要直接雙擊——這是內部測試 App、未經 Apple 簽章，直接雙擊會被 macOS 擋下。跳出的警告再按一次「打開」即可；之後就能正常雙擊。
3. 稍等幾秒，**電腦會自動跳出一個新的瀏覽器分頁**，這就是「設定精靈」。

> 💡 用它**自動開好的那個分頁**即可。

### 步驟 2：連線授權（精靈的第 1／3 步）
1. 按 **「開始授權」**。
2. 畫面會出現一組像 `A2CD-7FKM` 的**裝置代碼**。
3. 按 **「開核准頁」**（會開一個新分頁到 QuanQuant 網站的核准頁）。
4. 在核准頁的框裡**輸入剛才那組代碼** → 按「查詢」→ 核對代碼一致 → 按 **「核准」**。
5. 回到「設定精靈」那個分頁，它會**自己往下一步前進**（不用手動重整）。

> ⏰ 代碼 **10 分鐘內**要輸入完。過期的話，回精靈再按一次「開始授權」拿新代碼即可。

### 步驟 3：填永豐憑證（精靈的第 2／3 步）
1. 輸入你的永豐**模擬盤** **API Key** 與 **Secret Key**。
2. （選用）勾 **「記住永豐 API 憑證」**、**「記住裝置授權」**，下次啟動就免再輸入。
   - 勾了會存進**你自己電腦的鑰匙圈**；Mac 可能跳一次「鑰匙圈存取」授權視窗，按**允許**即可。
   - 不勾也沒關係，只是下次啟動要再走一次精靈。
3. 按 **「下一步」**。

### 步驟 4：確認並啟動（精靈的第 3／3 步）
核對畫面上的伺服器、模式（**sim**）、商品（**TXF**）、帳號無誤後，按 **「啟動」**。
接著會跳到「**Agent 狀態**」頁，看到**綠色徽章＝已連線**，就完成了！

---

## 三、開始測試下單

- 送出模擬單：回 **QuanQuant 網站的下單頁**即可。
- **Agent 會留在背景執行**（Dock 會出現它的圖示）以維持連線——這是正常的；**關掉瀏覽器分頁不會中斷連線**，也不用一直開著精靈視窗。
- **要完全關閉 Agent**：在 Dock 對它的圖示按右鍵 →「結束」。關筆電或結束後連線會斷（網站徽章變灰），要下單時重開 App 即可。

---

## 四、卡住了？對照這張表

| 狀況 | 怎麼辦 |
|---|---|
| 核准頁出現「下單子系統未啟用」或 `Forbidden` | 多半是你還沒登入，或管理員還沒把你的帳號加進允許名單。**聯絡管理員**。 |
| 代碼過期 / 找不到代碼 | 回精靈按「開始授權」拿新代碼，重新核准。 |
| 精靈一直停在「等待核准中……」 | 確認你在核准頁真的按了「核准」；若代碼已過期就重來一次。 |
| 瀏覽器對 `127.0.0.1` 顯示「不安全」 | **正常**，本機連線用的，可以繼續。 |
| 下次啟動又跳出精靈 | 你上次沒勾「記住」，屬正常；再走一次即可（或這次記得勾）。 |
| 徽章一直不是綠色 | 確認 Agent 視窗還開著、網路正常；仍不行找管理員。 |

---

## 五、這個精靈**不會**幫你做的事（需你自己處理）

- 申請永豐帳號、產生 API 金鑰
- 替你登入 QuanQuant 網站
- 替你在核准頁按「核准」

## 六、隱私說明

你的永豐 **API Key／Secret Key 只存在你自己這台電腦**（記憶體，或你若勾了「記住」則存於你電腦的作業系統鑰匙圈）。它**不會、也無法**被上傳到 QuanQuant 伺服器；伺服器只負責風控與下單決策，不持有任何人的永豐憑證。
