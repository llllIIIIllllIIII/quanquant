## 本輪的兩個查證發現（影響既有規劃，請先讀）

1. **場外單（手機 App／直連）不會進入系統的任何紀錄**——委託、成交、未平倉、已平倉全都不會。
   回報會送達但因比對不到 Order 而永久隔離（你們 `inbox_worker.py` 的 N1 註解已點名此情境），
   且 `positions_snapshot` 明寫「不呼叫 native API，BrokerPosition 是唯一真相來源」。
   先前列為「待工程實測」的那題就此結案。
2. **006 上線後會出現自相矛盾的畫面**：精簡條的可動用保證金取自券商 API（真實值，
   含場外部位佔用），未平倉卻取自系統帳——場外開一口後會顯示「保證金少一截、未平倉 0 口」。
   這是 R2-9 的直接動機。
