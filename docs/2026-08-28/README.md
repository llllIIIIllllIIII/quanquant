## 需要工程端回饋／查證的事項（散見各檔，此處彙總）

- Shioaji margin 查詢：欄位選擇（總保證金／權益數／可用保證金）、更新頻率、離線降級（F4 與 006 精簡條共用）
- Shioaji 是否推送「場外委託」的回報到本 API session（決定 quarantine 提示的實用性）
